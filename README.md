# ServiceNow-Based Employee Laptop Request Application

## Project Overview

This project is developed using ServiceNow to automate and manage
employee laptop requests through a centralized request management system.

## Business Objective

- Centralize employee laptop requests
- Provide Basic and Advance laptop request types
- Implement manager approval
- Prevent duplicate requests within the same year
- Track request status
- Automate notifications

## Technologies Used

- ServiceNow
- Service Catalog
- Flow Designer
- Business Rules
- ACL
- Approval Management
- Update Sets

## Key Features

1. Laptop Request Form
2. Basic / Advance Request Type
3. Manager Approval
4. Approval Status Tracking
5. Duplicate Request Validation
6. Automated Email Notification
7. Update Set Deployment
